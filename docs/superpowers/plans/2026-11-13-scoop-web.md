# Scoop Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or execute inline. Steps use checkbox (`- [ ]`) syntax for tracking. **Git commits optional** unless the user asks.

**Goal:** Ship a Next.js App Router frontend for Scoop on BSC: browse raffles, create, buy shares, draw, claim/refund against the Diamond.

**Architecture:** Single Diamond address via env. wagmi + injected connector + React Query. Read via view facets + `useReadContract` / multicall; writes via `useWriteContract`. IA from design spec (forkwiki/fork-inspired routes). Functional MVP UI — not a visual clone of fork.

**Tech Stack:** Next.js 15+ App Router, React 19, TypeScript, Tailwind, pnpm, Biome, wagmi v2, viem, TanStack Query. RainbowKit deferred (optional CDP deps break Next build).

**Spec:** `docs/superpowers/specs/2026-11-13-scoop-design.md`  
**Contracts:** `contracts/` (forge artifacts for ABI)

## Global Constraints

- Package manager: **pnpm only**
- Chinese UI copy for user-facing strings
- Native BNB = `address(0)` in forms and displays
- Fee display: 1% of creator proceeds only; winner gets 100% prize
- `NEXT_PUBLIC_SCOOP_DIAMOND` required; BSC chain id 56 (main) + 97 (test) + optional anvil 31337
- No heavy indexer in MVP — paginate via `nextOrderId` / token & user indexes + pending draw views
- YAGNI: no i18n framework beyond zh strings, no Farcaster miniapp, no subgraph
